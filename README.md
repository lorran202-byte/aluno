# Área do aluno — L.A. Consultoria

Página que o aluno abre pelo link enviado no app L.A. Consultoria: mostra o treino (fotos, vídeos, séries),
tem cronômetro de descanso e registra as séries/cargas feitas, que voltam para o app do personal.

Não guarda dados aqui: tudo vem do Firebase do personal, protegido pelas regras do Firestore.
